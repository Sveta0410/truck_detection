# Учет грузовиков на терминале логистического центра


## Вступление

Данный репозиторий включает в себя код, необходимый для развёртывания веб-сервиса для учёта грузовиков 
на терминале логистического центра, 
основанного на нейросетевой детектирующей модели YOLOv12 

## Установка и запуск
Для запуска необходимо склонировать репозиторий, установить все необходимые зависимости и запустить программу командой: 
```sh
uvicorn main:app
```
